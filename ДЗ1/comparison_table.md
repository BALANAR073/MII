# Сравнительная таблица AI-инструментов разработки

**Выполнил:** Творогов Д.Н.
**Задача:** веб-приложение «Трекер привычек» (React + Vite + Tailwind, бэкенд на Supabase)

## Шкала оценки

Оценка от 1 до 5, где **5 — лучше для моего проекта**:
- «Стоимость»: 5 — бесплатно или уже оплачено, 1 — дорого.
- «Безопасность данных»: 5 — код и данные остаются под моим контролем, 1 — всё хранится на стороне сервиса.

Критерии имеют разный вес. Вес определён по требованиям из отчёта (раздел 1): агент должен самостоятельно вести многошаговую работу в репозитории, поэтому важнее всего контекст и качество.

| Критерий | Вес |
|---|---|
| Доступ к контексту проекта | ×3 |
| Качество кода | ×3 |
| Удобство интеграции в рабочий процесс | ×2 |
| Требования к безопасности данных | ×2 |
| Скорость генерации кода | ×1 |
| Стоимость использования | ×1 |

Максимум: 5 × 12 = **60 баллов**.

## Обоснование оценок

### Bolt.new (Cloud)
- **Контекст — 3.** Видит весь проект, созданный внутри Bolt, но не мой локальный репозиторий. Существующий проект нужно импортировать.
- **Скорость — 5.** Рабочее приложение с превью в браузере за 1–2 минуты, без установки чего-либо.
- **Качество — 3.** Для прототипа хорошо. При доработке крупного проекта агент часто переписывает файлы целиком и ломает уже работающие части.
- **Стоимость — 3.** Бесплатно 1 млн токенов в месяц (не больше 300 тыс. в день), Pro — $25/мес за 10 млн токенов. Токены быстро уходят на исправления.
- **Безопасность — 2.** Код и среда выполнения находятся в облаке сервиса, данные передаются третьей стороне.
- **Интеграция — 2.** Работа только в браузере, своя среда. Проект выгружается в GitHub или скачивается, но вести разработку в своём репозитории неудобно.

### Lovable (Cloud)
- **Контекст — 3.** Как у Bolt: агент видит только проект внутри Lovable.
- **Скорость — 5.** Генерирует интерфейс и страницы очень быстро.
- **Качество — 3.** Хороший UI по шаблонам. Сложная бизнес-логика (расчёт серий, граничные случаи с датами) требует многих итераций.
- **Стоимость — 2.** Бесплатно 5 кредитов в день (около 30 в месяц), Pro — от $25/мес за 100 кредитов. Каждое сообщение агенту расходует кредиты, учебного проекта хватит ненадолго.
- **Безопасность — 2.** Код и данные хранятся в облаке Lovable.
- **Интеграция — 3.** Есть двусторонняя синхронизация с GitHub и встроенная интеграция с Supabase, что подходит под мой стек.

### Replit Agent (Cloud)
- **Контекст — 3.** Агент видит проект в облачной IDE Replit.
- **Скорость — 4.** Быстро разворачивает проект вместе с хостингом, но агент дольше «думает» над задачами.
- **Качество — 3.** Рабочий код, архитектура обычно упрощённая.
- **Стоимость — 3.** Бесплатный тариф Starter ограничен. Core — $20/мес с $20 кредитов, а агент списывает их в зависимости от сложности задачи.
- **Безопасность — 2.** Всё выполняется на серверах Replit.
- **Интеграция — 2.** Своя облачная IDE. Работа с локальными инструментами и тестами ограничена.

### Cursor (IDE)
- **Контекст — 5.** Индексирует весь локальный репозиторий, можно указывать файлы через `@`.
- **Скорость — 4.** Быстрое автодополнение (Tab), агентный режим выполняет задачи за минуты.
- **Качество — 4.** Выбор моделей, в том числе топовых. Качество зависит от выбранной модели.
- **Стоимость — 3.** Hobby бесплатный с ограничениями. Pro — $20/мес с кредитным пулом, премиум-модели быстро его расходуют. Оплата из РФ затруднена.
- **Безопасность — 4.** Код хранится локально, есть Privacy Mode. Фрагменты кода всё равно отправляются в облачные модели.
- **Интеграция — 5.** Полноценная IDE на базе VS Code: расширения, git, терминал.

### GitHub Copilot (IDE-плагин)
- **Контекст — 4.** Работает с открытым репозиторием в VS Code или JetBrains, есть агентный режим. Самостоятельно ведёт многошаговые задачи хуже, чем CLI-агенты.
- **Скорость — 5.** Лучшее в классе мгновенное автодополнение.
- **Качество — 4.** Хорошее качество, выбор моделей.
- **Стоимость — 5.** Есть бесплатный тариф. Pro — $10/мес. Для студентов Pro доступен бесплатно через GitHub Education.
- **Безопасность — 4.** Код локальный, отправляемые фрагменты не используются для обучения на платных тарифах.
- **Интеграция — 5.** Плагин в привычную IDE, глубокая интеграция с GitHub.

### Claude Code (CLI)
- **Контекст — 5.** Работает прямо в папке проекта, сам читает и ищет файлы, запускает команды (тесты, git, npm). Постоянный контекст проекта задаётся файлом `CLAUDE.md`.
- **Скорость — 4.** Не мгновенное автодополнение, а агент. Выполняет задачу целиком: пишет код, запускает тесты, исправляет.
- **Качество — 5.** Модели Claude сильны в коде. Агент сам проверяет результат тестами (в моём тесте сам нашёл баг с часовыми поясами, см. отчёт).
- **Стоимость — 4.** Входит в подписку Claude Pro ($20/мес), которая у меня уже есть, поэтому дополнительных затрат нет. Лимиты Pro при интенсивной работе заканчиваются, отсюда 4, а не 5.
- **Безопасность — 4.** Код хранится локально. Агент спрашивает разрешение на изменение файлов и выполнение команд, можно запретить отдельные действия. Фрагменты кода отправляются в облако Anthropic.
- **Интеграция — 4.** Терминал, расширения для VS Code и JetBrains, git, поддержка MCP. Для тех, кто привык работать только мышью в IDE, нужно время на освоение.

## Итог

По взвешенной оценке выбран **Claude Code** (54 из 60). Близкие альтернативы — Cursor и GitHub Copilot (по 52). Облачные агенты (33–35) хорошо подходят для быстрого прототипа, но проигрывают по контексту, безопасности и интеграции в работу с собственным репозиторием. Подробное обоснование — в `report.md`, раздел 3.
