# «ПоРовну» — тестовый проект

Проект для проверки работы Claude Code перед разработкой приложения «ПоРовну»
(делёж общих расходов в компании: кто за что платил и кто кому сколько должен).

## Стек
- Node.js 18+, ES-модули (`"type": "module"`)
- Тесты: встроенный раннер `node:test` + `node:assert/strict`, без внешних зависимостей

## Команды
- `npm test` — запустить все тесты

## Правила
- Все денежные суммы — целые числа в копейках; никаких float-рублей в расчётах
- Остаток от деления раздаётся по копейке детерминированно; сумма балансов всегда 0
- Каждая экспортируемая функция покрыта тестами (позитивные сценарии + ошибки)
- Комментарии и сообщения об ошибках — на русском
