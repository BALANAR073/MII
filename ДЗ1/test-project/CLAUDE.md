# Habit Tracker — тестовый проект

Проект для проверки работы Claude Code перед разработкой трекера привычек.

## Стек
- Node.js 18+, ES-модули (`"type": "module"`)
- Тесты: встроенный раннер `node:test` + `node:assert/strict`, без внешних зависимостей

## Команды
- `npm test` — запустить все тесты

## Правила
- Даты в формате `YYYY-MM-DD`, арифметика дат только в UTC
- Каждая экспортируемая функция покрыта тестами (позитивные сценарии + ошибки)
- Комментарии и сообщения об ошибках — на русском
