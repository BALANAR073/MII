# ПоРовну — делим общие расходы без споров

Веб-приложение для дележа общих расходов в компании: поездка, съёмная квартира, праздник. Участники записывают, кто за что заплатил и на кого делится расход. Приложение показывает балансы и минимальный список переводов «кто кому должен» — с точностью до копейки.

Учебный проект по дисциплине «Методы искусственного интеллекта» (КАИ), ДЗ4 «Разработка Frontend-приложения с AI-агентом». Выполнил: Творогов Д.Н., гр. 4481.

- Требования: [`../../ДЗ3/technical_specification.md`](../../ДЗ3/technical_specification.md) (ТЗ 1.1), истории и критерии приёмки: [`../../ДЗ3/user_stories.md`](../../ДЗ3/user_stories.md).
- Макет: концепция 1 «Минимализм» из [`../../ДЗ3/ui_concepts/ui_description.md`](../../ДЗ3/ui_concepts/ui_description.md), плюс блок «Кто кому должен» из концепции 2 и десктопная раскладка из концепции 3.
- Отчёт о разработке: [`../development_report.md`](../development_report.md).

## Что умеет

| Функция | Требования ТЗ |
|---|---|
| Список групп со своим балансом, создание группы с эмодзи | FR-2.1, FR-2.2 |
| Лента расходов, добавление (поровну или по долям), изменение и удаление своих расходов с отменой 5 с | FR-3.1–3.5 |
| Балансы участников с полосками, «Кто кому должен» (не больше N−1 переводов) | FR-4.1–4.6 |
| «Рассчитаться» и «Отметить перевод», в том числе частичный | FR-5.1 |
| История операций | FR-5.2 |
| Приглашение (копирование ссылки), выход из группы при нулевом балансе | FR-2.3, FR-2.4 |
| Состояния loading / error / empty, тексты ошибок из ТЗ, повтор запроса | NFR-9, раздел 6 |
| Адаптивность 360–1440 px: одна колонка на телефоне, две от 1024 px, три от 1280 px | NFR-1 |

Деньги хранятся только в целых копейках, остаток при делении раздаётся по копейке в порядке вступления в группу. Сумма балансов группы всегда равна нулю — это проверяют тесты.

Бэкенда пока нет: данные хранит mock-API (`src/mocks/`) в памяти и в `localStorage` браузера. Supabase подключается в ДЗ5. Текущий пользователь — **Боря**.

## Стек

React 18, TypeScript 5 (strict), Vite, Tailwind CSS 3, React Router 6. Тесты — Vitest и React Testing Library. Сторонних UI-библиотек нет.

## Запуск

Нужен Node.js 20 или новее.

```bash
cd ДЗ4/poravnu
npm install        # установить зависимости
npm run dev        # dev-сервер с hot reload: http://localhost:5173
```

Другие команды:

| Команда | Что делает |
|---|---|
| `npm test` | все автотесты (141 тест, 18 файлов) |
| `npm run test:watch` | тесты в режиме наблюдения |
| `npm run typecheck` | проверка типов TypeScript |
| `npm run build` | проверка типов и сборка в `dist/` |
| `npm run preview` | просмотр собранной версии |

### Демо-режимы для проверки состояний

Добавьте параметр к адресу:

| Адрес | Что показывает |
|---|---|
| `/?mock=reset` | вернуть исходные демо-данные |
| `/groups/kazan?mock=error` | сетевая ошибка при загрузке и кнопка «Повторить» (ERR-3) |
| `/?mock=server` | ошибка сервера 500 (ERR-5) |
| `/groups/kazan?mock=slow` | ответы по 12 секунд: скелетоны и предупреждение о долгом ответе (ERR-11) |
| `/?mock=empty` | у пользователя нет групп (ERR-2) |

Проверить мобильную вёрстку на компьютере можно в Chrome: F12 → значок телефона (Device Toolbar) → например, iPhone SE (375 px) или Galaxy S8 (360 px).

## Структура

```text
src/
  app/          роутинг, каркас, текущий пользователь, общие хуки (useResource, useMutation, useMediaQuery)
  pages/        экраны: GroupsPage, GroupPage, HistoryPage
  features/
    balances/   расчёт балансов и переводов (чистые функции) и их UI
    expenses/   форма и лента расходов, валидация, оптимистичное добавление, отложенное удаление
    groups/     список групп, шапка группы, создание группы
    transfers/  отметка перевода
  components/ui переиспользуемые компоненты: Button, Dialog, Toast, Skeleton, Avatar…
  lib/          деньги (formatRub, parseRubToKop), деление, русские падежи, даты
  mocks/        mock-API, демо-данные, демо-режимы (в ДЗ5 заменяется на Supabase)
  types/        типы предметной области и контракт API
```

Бизнес-логика (деление, балансы, переводы) — только в чистых функциях без React, компоненты получают данные через хуки. Правила кода для AI-агента — в [`CLAUDE.md`](CLAUDE.md) (22 правила из ДЗ2 и ссылка на требования).

## Тесты

141 тест в 18 файлах:

- **расчёты:** деньги и разбор суммы, деление по долям, балансы, переводы «кто кому должен», тексты балансов, падежи, производительность (50 участников и 1000 расходов быстрее 50 мс);
- **хуки и компоненты:** загрузка данных (`useResource`), модальное окно (фокус, Esc), форма расхода, отложенное удаление на фейковых таймерах;
- **экраны:** «Мои группы», «Группа», «История» — загрузка, сетевая ошибка и повтор, пустые состояния, чужая группа, отметка перевода, ошибка сохранения, оптимистичное добавление с откатом, удаление с отменой, просмотр чужого расхода;
- **доступность:** axe-core (`vitest-axe`) на экранах «Мои группы», «Группа» и в форме расхода.

Названия тестов ссылаются на критерии приёмки из ДЗ3 (`AC-04.2`, `AC-08.3` и т. д.).
